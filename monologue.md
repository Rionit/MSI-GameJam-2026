# FIRST TIME EXPLANATIONS
## Breakers
You need to turn all the switches on in order to boot up the server.

## Matrix
In order to protect their security codes, they set up a partially-blocked hash matrix that needs to be fully decoded. You need to select a cell for each row and column, but the hash prohibits you from selecting more than one cell per row or column.

## Antivirus
I sent you a small code snippet, which you have to take past the system firewalls. The antivirus keeps scanning the layers, avoid it.

## Pipe flow
Most of their security data travel through secure hubs. I highlighed the ports that need to be forwarded on the outside of the hub you see before you. Make a tunnel between them so I can damage their security structure.

## Graetz
Before they left, they broke some electrical circuits that power up some of my systems. Rotate the diodes so the electrical current flows from + to + and from - to - all the time. In the first wave, the AC's + is on the upper pin, in the second, the + and - switch for AC.
